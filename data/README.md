# Data

`regulations/` holds 21 CFR Part 11 (electronic records and signatures), Part 210 and
Part 211 (current good manufacturing practice for finished pharmaceuticals), one Markdown
file per section. U.S. federal regulations are in the public domain. The files come from
the eCFR mirror at https://github.com/AlextheYounga/ecfr, which states it is synced
through 2025. Check https://www.ecfr.gov for the current text before relying on any passage.

`proposals/` holds three fictional company proposals written for this project. They do
not describe any real company.
